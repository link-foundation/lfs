LFS disk blueprint

Every byte of an LFS volume of any configuration, from the volume down to each field of the superblock, the journal, the chunk tables, every links record and index cell, and each file's extent. LFS itself, built for WebAssembly, formats the volume in your browser. Pick a configuration or open an image (lfs demo demo.img makes one). Click a region to open it, or click a byte to find the field that holds it. The block-level view is the disk-space map.

Configuration

Format keys (lfs demo --help) and runtime keys (lfs config --help) · ?config=key=value;… · • marks a changed key
